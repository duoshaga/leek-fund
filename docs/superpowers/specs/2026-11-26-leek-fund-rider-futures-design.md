# 韭菜盒子 Rider 适配方案

首版交付一个可从磁盘安装的 Rider 插件 ZIP。在侧栏管理股票、基金、国内期货和海外期货自选，选一个标的固定到底部状态栏。收起侧栏继续写代码时，仍能看到最新一笔报价及涨跌幅。

开发基线为原仓库 `J:\Tools\Leek` 的 `master@425bc794`，公开源码版本为 `3.24.0`。首个验收环境为本机 Windows 上的 JetBrains Rider `2026.3.0.2`（`RD-263.7307.355`）。[上游源码清单](https://github.com/LeekHub/leek-fund/blob/425bc79484218064e4ecdb1dea272733befabbd4/package.json#L5)

## 期货的报价和交易时段

- **涨跌幅。** 首版对齐上游同一合约的显示口径。沪深 300 股指期货按昨收计算，螺纹钢和上述两种外盘品种按昨结算价计算。详情提示标明所用基准。基准缺失或为零时显示「—」。[期货字段解析与涨跌计算](https://github.com/LeekHub/leek-fund/blob/425bc79484218064e4ecdb1dea272733befabbd4/src/explorer/stockService.ts#L333)
- **外盘报价。** 优先显示有效成交价。盘口齐备且成交价落在买卖价区间外时，沿用上游的买一回退规则。成交价缺失但有买一时，也取买一。两种情况下，侧栏和状态栏都标注「买一」，以该价对昨结算价计算涨跌幅，提示中单列源成交价。两种价格均缺失时显示「—」。[上游外盘价格处理](https://github.com/LeekHub/leek-fund/blob/425bc79484218064e4ecdb1dea272733befabbd4/src/explorer/stockService.ts#L420)
- **夜盘。** 按交易所、品种、交易日历和时区决定自动刷新时段，保留行情源的报价时间。上期所螺纹钢常规夜盘到 23:00，黄金到次日 02:30。同一个晚间可以出现螺纹钢已休市、黄金仍在刷新的情况。夜盘所属交易日按交易所日历判定。布伦特和富时中国 A50 都列入首版自动刷新范围，分别按行情源标的核对时区、开闭市规则和休市日。其他尚未核实交易时段的合约可手动刷新。[上期所交易时间](https://www.shfe.com.cn/services/calenderandholidays/tradinghours/)
- **合约识别。** 始终保留完整行情代码。`nf_RB0` 和 `nf_RB2701` 可同时加入自选，状态栏固定项可以在两者之间切换。到期或暂缺数据的合约保留原条目，并标明最后报价时间或「暂无报价」。

## Rider 实现方式

在原仓库增加 `rider-plugin/` 模块，用 Kotlin 和 IntelliJ Platform Gradle Plugin 构建。侧栏采用原生 Tool Window，底栏采用 Status Bar Widget。用同一份 IDE 级自选设置保存代码和固定项，多开解决方案时共享报价与请求。网络请求在后台执行，侧栏和状态栏读取同一份报价。断网时保留最后一笔及其原始时间，恢复后自动续更。[Rider 插件开发](https://plugins.jetbrains.com/docs/intellij/rider.html) · [工具窗口](https://plugins.jetbrains.com/docs/intellij/tool-windows.html) · [状态栏组件](https://plugins.jetbrains.com/docs/intellij/status-bar-widgets.html)

上游行情服务直接创建 VS Code 树节点，Rider 端用 Kotlin 重写请求、解析与界面绑定，沿用合约代码和经样本核对的计算规则。第二阶段用内置浏览器 JCEF 承载可复用的 React 详情页面，将消息通信和静态资源路径接到 Rider。期货分时图接分钟行情，日 K 线接日线开盘、最高、最低和收盘价。基金曲线使用已公布净值序列。[上游前端通信](https://github.com/LeekHub/leek-fund/blob/425bc79484218064e4ecdb1dea272733befabbd4/template-packages/leek-center/src/utils/common.ts#L15) · [JetBrains 内置浏览器](https://plugins.jetbrains.com/docs/intellij/embedded-browser-jcef.html)

## 交付顺序和工期

| 阶段 | 可验收成果 | 单人工期估算 |
|---|---|---|
| 一 · 日常看盘 | 可安装 ZIP。四组自选均可按代码添加、删除、固定到状态栏。支持手动刷新、开市自动刷新、重启恢复设置 | 4–7 人日 |
| 二 · 图表与提醒 | 从自选打开股票和期货的当日分时图、日 K 线，以及基金历史净值曲线。补股票和基金的基础持仓盈亏、价格阈值提醒、导入 VS Code 自选清单 | 另约 4–7 人日，以验收标的均有可用图源为前提 |
| 三 · 扩展覆盖 | 按优先级接入美股、外汇、数字货币、快讯和 AI。新版 README 中的 Pro 功能按可用源码和接口单项估算 | 选定功能后估算 |

第二阶段用表中两只股票和五个期货标的逐一验收当日分时与日 K，用两只基金验收净值曲线。任一标的缺少一种图源时，该图保留为待交付并单独估算补源工期。持仓盈亏用固定账本核对，提醒验证同一次穿越阈值只触发一次，导入自选时已有代码自动去重。

## 首版验收

1. 在原仓库构建插件并运行 Plugin Verifier，在上述 Rider 版本中从磁盘安装 ZIP，打开「韭菜盒子」工具窗口。
2. 按表中代码添加四组样本。用同一笔源行情核对价格、涨跌基准和时间。把指定月份期货固定到底栏，收起侧栏后观察更新，重启 Rider 后核对自选和固定项。以同一笔外盘买一回退样本复算涨跌幅并核对两处「买一」标注。
3. 用可控时钟回放螺纹钢收盘前后和沪金 23:59 到次日 00:01 两种情况，核对轮询与交易日归属。布伦特和富时中国 A50 分别在实际开市时观察至少两个自动刷新周期，与源报价核对。其间覆盖一次 A 股已收盘、外盘仍开市的场景。
4. 模拟断网和恢复，验证旧报价带有最后更新时间，同一标的在两个 Rider 窗口中共享一次轮询。接口返回空数据时检查空值显示。
